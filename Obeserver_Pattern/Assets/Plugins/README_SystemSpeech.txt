Place System.Speech.dll here for Windows Editor/Standalone.
Recommended path on most systems:
C:\\Windows\\Microsoft.NET\\Framework64\\v4.0.30319\\System.Speech.dll

Unity import settings:
- Select the DLL in Project window
- Inspector > Select platforms: Editor and Windows Standalone only
- CPU: Any CPU

Also ensure scripting define symbol USE_SYSTEM_SPEECH is set (already added).
